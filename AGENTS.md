## Modo de operação dos agentes (Claude Code e Codex)
- O dono (Miguel/SAV1BOY) autoriza os agentes a agir de forma autônoma neste repositório: ler e editar arquivos,
  instalar dependências, rodar build/teste/lint, commitar, dar push e fazer deploy quando a tarefa pedir.
- Proibido: force-push, reescrever histórico, apagar o sistema, ler ou commitar `.env` de produção e segredos.
- Só acrescente em arquivos de instruções (CLAUDE.md, AGENTS.md); não apague o que outra pessoa escreveu.
- Comandos: teste `ver README` · lint `ver README` · build `npm run build`
